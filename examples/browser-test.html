NeuraiHW · Post-Quantum address (Testnet)

Reads device info over Web Serial using ../dist/browser.js. The device exposes only its ML-DSA-44 public key; this page derives the tnq1… address from that pubkey and the mode declared in info (key_type=pq, network=NeuraiTest).

Requires a browser with Web Serial (Chrome/Edge/Opera) and serving this folder over HTTP (e.g. npx serve . from the repo root), not opening it via file://.
